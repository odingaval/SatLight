# Design System Brief

## Brand direction
Name: Satlight (sats + lightning + spotlight on contributors). Feel: fast, trustworthy, builder-friendly, warm.

## Tokens (proposed, verify contrast)
| Token | Value | Use |
|---|---|---|
| Ground | #FFFFFF / #121212 (dark) | Backgrounds |
| Text | #222222 / #F2F2F2 | Body |
| Muted | #595959 / #A8A8A8 | Secondary text (4.5:1) |
| Accent (sat orange) | #B45309 | Reward amounts, key actions |
| Success / Warning / Error | choose accessible set | Status |

Typography: one clean sans for UI, one monospace for sats, hashes, and code. Scale 14/16/20/24/34/48.

## Components
Bounty card, difficulty badge, reward chip (sats + approx fiat), status timeline, QR invoice panel, wallet balance cards, form fields, tables, toasts, banners (payouts paused), empty states.

## Principles
Sats first, fiat second. Explain money events in plain language. Real buttons and links, keyboard accessible, 44px touch targets, WCAG 2.1 AA, never color alone.

## Open items
Logo (bolt inside spotlight concept), final palette, mobile layouts, dark mode.
