# ADR-009: Project license

- **Status:** Proposed
- **Date:** 2026-10-21

## Context
The platform's audience values open source. A hosted competitor could otherwise run a closed fork.

## Decision
License under AGPL-3.0, with the Satlight name and logo as reserved trademarks.

## Consequences
Keeps network-hosted forks open. Some enterprises avoid AGPL. Contributors agree to the project license via CONTRIBUTING.md; consider a DCO.
