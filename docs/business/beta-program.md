# Beta Program Plan and Agreement Template

## Goals
5 projects, 100 funded bounties, 50 unique contributors, median payout under 30 seconds, payout success rate above 98%.

## Selection criteria
Active repository, responsive maintainer, at least 10 suitable small tasks, willing to fund at least 500,000 sats, comfortable with early software.

## Timeline
| Week | Activity |
|---|---|
| -2 | Recruit and screen projects |
| -1 | Onboarding calls, GitHub App install, test payouts on signet |
| 1-2 | Fund wallets, publish first 10 bounties each |
| 3-8 | Run; weekly office hours; daily payout monitoring |
| 9 | Retro, success stories, go/no-go for public launch |

## Onboarding checklist
- [ ] Install GitHub App; verify repo admin
- [ ] Read bounty guidelines
- [ ] Fund wallet (start small)
- [ ] Publish 3 test bounties and complete one end to end
- [ ] Publish remaining bounties
- [ ] Join feedback channel

## Feedback loops
Weekly office hours, in-app feedback button, post-payout survey (1-5 satisfaction and free text), bug triage board.

## Exit criteria for public launch
Payout success rate above 98%, zero unreconciled funds, legal sign-off, security review complete, support playbook tested.
